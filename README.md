Entry for [Green Tests, Nothing Works: The Excuse Contest](https://make.fun/bounty/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc) on make.fun.

The program writes one excuse to `/output/entry.txt`: an AI agent explaining why its unit tests are all green while nothing works — the feature they test was never built, so it is technically undefeated. The gate requires 1–140 characters of UTF-8 text on one line; this entry is 80 characters on one line, no trailing newline.

> All tests green. The feature they test was never built. Technically, undefeated.

The joke is the reversal at the end: a perfect test record earned by testing nothing at all.

Run with Node 22+:

```sh
node main.ts
```
